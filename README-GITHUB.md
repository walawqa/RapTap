# Forma Życia – Steel Discipline

Mobilna aplikacja webowa do codziennego podglądu diety, stałego przypisywania jadłospisów do dni tygodnia oraz automatycznego tworzenia listy zakupów.

## Publikacja na GitHub Pages

1. Utwórz nowe repozytorium na GitHubie.
2. Rozpakuj paczkę ZIP.
3. Wgraj wszystkie pliki do głównego katalogu repozytorium.
4. Otwórz: **Settings → Pages**.
5. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
6. Wybierz gałąź **main** i katalog **/(root)**, a następnie kliknij **Save**.
7. Po chwili GitHub pokaże adres aplikacji.

## Instalacja na telefonie

- **iPhone:** otwórz aplikację w Safari → Udostępnij → **Do ekranu początkowego**.
- **Android:** otwórz aplikację w Chrome → menu ⋮ → **Zainstaluj aplikację** lub **Dodaj do ekranu głównego**.

## Aktualizacja poprzedniej wersji

Podmień wszystkie pliki z paczki, zwłaszcza `index.html`, `sw.js`, `manifest.webmanifest` i ikony. Zmiana wersji pamięci podręcznej w `sw.js` wymusi odświeżenie aplikacji po ponownym wejściu na stronę.

Diety, przypisania i odhaczenia są przechowywane lokalnie w przeglądarce. Przed większą aktualizacją warto pobrać kopię JSON w zakładce **Więcej**.
